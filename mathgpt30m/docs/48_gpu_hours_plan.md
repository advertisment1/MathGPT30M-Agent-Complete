# 固定 30M 数学 GPT：48 GPU-hours 实验协议

## 决策
- 正式模型：固定约 30M 参数，必须运行时实际统计；无需训练理论最优 N*。
- 理论研究：同架构家族训练 3 个代理规模 × 3 个 token 预算，共 9 点，每点一个 seed；用 SciPy least_squares 拟合 E,A,B,alpha,beta。
- 数据：同一 tokenizer、冻结验证集、相同数学数据来源和优化器设置；各训练预算必须准确记录实际消耗的 token 数。

## 时间上限（单 GPU，非多 GPU 相加）
| 任务 | 上限小时 |
|---|---:|
| 部署 / 数据 / 正确性验证 | 4 |
| 六轮消融初筛及必要复核 | 6 |
| 代理 scaling 网格 | 8 |
| 固定 30M 正式训练 | 26 |
| 评估、修复、缓冲 | 4 |
| 总计 | 48 |

## 执行与决策门槛
1. 先用 10-20 分钟跑 30M 模型，测 tokens/s、峰值显存和 validation loss；估算可完成 token 数。
2. 每个代理规模跑 5M、15M、40M tokens（总计 180M 代理训练 tokens），实际耗时超过 8h 就停，不虚构缺失点。
3. 使用相同 held-out validation 文本和 tokenizer；训练 token 预算 D 指累计被模型看过的 token（重复采样要记录），不能等同唯一 token 数。
4. 模型族固定层宽比、头维、GQA 比率等结构规则；实际参数量以模型统计为准。现有 JSON 为起始提案，不保证严格结构相似。
5. 记录每次 N、D、val loss、seed、硬件、tokens/s、训练时长、配置 hash。
6. 拟合 L(N,D)=E+A(N/1e6)^(-alpha)+B(D/1e6)^(-beta)，并报告 RMSE、残差、外推风险；仅 9 点拟合 5 参数很脆弱。
7. 预算 C_flops 需用实际吞吐测算，不能把 48 GPU-hours 当作 FLOPs；通过 C≈6ND 求 N*、D*，此近似忽略注意力二次项。
8. 30M 正式训练优先：如数据预处理或网格超时，压缩代理实验而不是取消正式训练。
9. WSD：线性 warmup、stable、线性 decay；在正式训练开始前根据预计 steps 设置，预留尾部 decay；延长 stable 需要重新定义衰减起点并记录。
10. 后训练 SFT 不在本轮 48h 基线交付中；先评估预训练模型的困惑度、生成能力，再考虑数学题解 SFT。

## 重要限制
当前项目已有训练和拟合脚本，但没有全自动代理网格调度器，也未在云 GPU 实测，时间分配只是初始预算。
